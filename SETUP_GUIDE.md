# SmartDeal: guia de instalação e configuração

Tudo é feito pelo navegador, sem instalar programas e sem custo.

## Contas necessárias (todas gratuitas)
1. GitHub: guarda o código.
2. Supabase: banco de dados e login.
3. Vercel: publica o site.

## Como o site é atualizado
1. O código fica no repositório do GitHub.
2. Ao salvar uma alteração ("Commit changes"), a Vercel publica a nova versão automaticamente em cerca de 1 minuto.

## Cuidado ao criar arquivos no GitHub
Comece sempre pela página principal do repositório. Se você clicar em "Add file" dentro de uma pasta, o nome do arquivo já começa com o caminho dessa pasta.
